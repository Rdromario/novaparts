# Nova Parts and Services — sitio institucional

Sitio estático responsive en español (Paraguay), preparado para publicar en GitHub + Cloudflare Pages.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: identidad visual, diseño responsive y componentes.
- `script.js`: menú móvil y filtros del catálogo.
- `assets/`: logotipo y fotografías extraídas del material institucional proporcionado.

## Publicación en Cloudflare Pages
1. Crear un repositorio en GitHub y subir el contenido de esta carpeta (los archivos deben quedar en la raíz del repositorio).
2. En Cloudflare, ir a **Workers & Pages → Create → Pages → Connect to Git**.
3. Seleccionar el repositorio.
4. Framework preset: **None**.
5. Build command: dejar vacío.
6. Build output directory: `/`.
7. Guardar y desplegar.

No requiere Node, npm ni proceso de compilación.
